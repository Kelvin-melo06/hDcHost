# 🚀 hDcHost - Página Inicial Responsiva

Este projeto consiste na criação de uma landing page (página inicial) para a empresa fictícia hDcHost, especializada em serviços de hospedagem de sites e registro de domínios. O objetivo principal é demonstrar habilidades em construção de interfaces web, priorizando a responsividade, a usabilidade e uma estrutura de código limpa e semântica.


---

## ✨ Funcionalidades Principais

* **Navegação Interativa:** Barra de navegação com logo e itens de menu, incluindo um botão de "Entrar", otimizada para diferentes tamanhos de tela.
* **Banner Hero Impactante:** Seção de destaque inicial com título e slogan sobre uma imagem de fundo, projetada para engajar o usuário.
* **Seção de Benefícios/Serviços:** Apresenta os pilares da hDcHost (Segurança, Performance, Suporte) em blocos de conteúdo bem organizados, que se adaptam de uma coluna (mobile) para três colunas (desktop).
* **Cards de Planos e Preços:** Exibe os diferentes planos de hospedagem em cards visuais, com destaque para o preço e lista de funcionalidades, organizados em colunas responsivas.
* **Formulário de Verificação de Domínio:** Permite ao usuário verificar a disponibilidade de um domínio, com sugestões de extensões via `datalist`.
* **Formulário de Contato:** Uma seção dedicada para o usuário enviar mensagens, garantindo a comunicação com a equipe.
* **Design Moderno e Responsivo:** O layout é totalmente adaptável, garantindo uma excelente experiência de usuário em celulares, tablets e desktops.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Para a estrutura e semântica do conteúdo.
* **CSS3:** Para a estilização e o layout, com foco em:
    * **Flexbox:** Utilizado amplamente na navegação, banner, e para organização interna de elementos.
    * **CSS Grid:** Essencial para o layout de múltiplos itens em colunas (blocos de conteúdo e cards de planos), garantindo espaçamento e alinhamento precisos.
    * **Media Queries:** Implementadas com a abordagem **Mobile-First**, garantindo que o design se adapte progressivamente a diferentes tamanhos de tela (breakpoints em 768px, 1024px, 1200px).
    * **Box Model & `box-sizing: border-box;`:** Aplicado globalmente para controle previsível do dimensionamento dos elementos.
    * **Propriedade `position`:** Utilizada para efeitos de sobreposição (banner/conteúdo) e posicionamento preciso de elementos.
* **Google Fonts:** Para tipografia (`Inter`, `Oswald`, `Sansation`).
